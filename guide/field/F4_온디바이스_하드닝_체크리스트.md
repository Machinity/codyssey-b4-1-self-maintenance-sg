# F4. 서비스 로봇 온디바이스 하드닝 체크리스트

출하 전 점검이나 현장 정기 점검에 쓰는 형식입니다. **✅ = 이 미션에서 수행함**, ⬜ = 현장에서 추가로 필요.
각 항목의 "확인 명령"을 VM 에서 실행해 보고, 미션 범위 밖 항목은 "왜 필요한지"를 설명할 수 있으면 됩니다.

## A. 원격 접근 (SSH)

| # | 항목 | 확인 명령 | 미션 |
|---|---|---|---|
| A1 | 기본 포트 변경 | `sudo sshd -T \| grep '^port '` | ✅ |
| A2 | root 원격 로그인 차단 | `sudo sshd -T \| grep permitrootlogin` → `no` | ✅ |
| A3 | 비밀번호 인증 비활성, 공개키만 | `sudo sshd -T \| grep passwordauthentication` → `no` | ⬜ (F2 §1) |
| A4 | 인증 시도 제한 | `sudo sshd -T \| grep maxauthtries` | ✅(선택 설정) |
| A5 | 접속 가능 그룹 제한 | `sudo sshd -T \| grep allowgroups` | ⬜ |
| A6 | 반복 실패 IP 차단 | `sudo fail2ban-client status sshd` | ⬜ (F2 §2) |
| A7 | SSH 는 VPN/관리망에서만 | `sudo ufw status` 의 `on wg0` 규칙 | ⬜ (F2 §3) |
| A8 | OOB(대체 접근 경로) 확보 | 운영 문서 | ⬜ |

## B. 네트워크

| # | 항목 | 확인 명령 | 미션 |
|---|---|---|---|
| B1 | 방화벽 활성 + 부팅 시 유지 | `sudo ufw status verbose`, `systemctl is-enabled ufw` | ✅ |
| B2 | 기본 거부(incoming) | `Default: deny (incoming)` | ✅ |
| B3 | 필요한 포트만, 프로토콜 명시 | `sudo ufw status numbered` | ✅ |
| B4 | IPv6 도 동일 정책 | `(v6)` 규칙 존재 | ✅ |
| B5 | LISTEN 포트 = 허용 포트 (불필요 서비스 없음) | `sudo ss -tulnp` 와 ufw 규칙 대조 | ✅(부분) |
| B6 | 외부 실측 감사 | 외부에서 `nc -vz` / `nmap` | ✅(02장 2-7) |
| B7 | 출발지 제한 (관제망만) | `ufw allow from <대역> ...` | ⬜ |
| B8 | 나가는 트래픽 제한 | `Default: ... deny (outgoing)` | ⬜ (F2 §4) |
| B9 | Docker 포트 우회 점검 | `sudo iptables -S DOCKER` , 외부 실측 | ⬜ |
| B10 | 불필요한 네트워크 서비스 제거 | `systemctl list-units --type=service --state=running` (avahi, cups 등) | ⬜ |

## C. 계정과 권한

| # | 항목 | 확인 명령 | 미션 |
|---|---|---|---|
| C1 | 역할별 계정, 공용 계정 없음 | `getent passwd \| awk -F: '$3>=1000'` | ✅ |
| C2 | 역할별 그룹 | `getent group agent-common agent-core` | ✅ |
| C3 | 서비스는 일반 계정으로 실행 | `ps -o user -C agent-app-linux` | ✅ |
| C4 | sudo 최소 권한(명령 단위) | `sudo -l -U agent-admin` | ✅ |
| C5 | 서비스 전용 계정은 로그인 불가 | `getent passwd agent-svc` 셸이 `nologin` | ⬜ (03장 현장 노트) |
| C6 | 사용하지 않는 계정 잠금 | `sudo passwd -S -a \| grep ' P '` | ⬜ |
| C7 | cron 사용자 제한 | `/etc/cron.allow` | ⬜ |
| C8 | sudo 사용 감사 | `journalctl _COMM=sudo` | ✅(확인 방법 학습) |

## D. 파일시스템과 데이터

| # | 항목 | 확인 명령 | 미션 |
|---|---|---|---|
| D1 | 공유/보안 디렉토리 분리 | `sudo namei -l $AH/api_keys` | ✅ |
| D2 | setgid + default ACL 로 일관된 공유 | `sudo getfacl $AH/upload_files` | ✅ |
| D3 | 비밀 파일 other 권한 없음 | `sudo find $AH/api_keys -perm /o=rwx` → 결과 없음 | ✅ |
| D4 | 실행 환경 설정 변조 방지 | `ls -l /etc/agent-app/agent.env` → `root` 소유 | ✅ |
| D5 | 업로드 영역 `noexec` | `findmnt -no OPTIONS <업로드 마운트>` | ⬜ |
| D6 | 디스크 암호화 | `lsblk -f` 에 `crypto_LUKS` | ⬜ |
| D7 | world-writable 파일 없음 | `sudo find / -xdev -type f -perm -0002 2>/dev/null` | ⬜ |
| D8 | 기기별 키, 교체 주기 | 운영 문서 | ⬜ |
